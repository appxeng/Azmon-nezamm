راهنمای گرفتن اپ از GitHub (قدم‌به‌قدم)
=========================================

کار GitHub چیست؟ دو کار برای شما انجام می‌دهد:
  الف) APK را خودش می‌سازد (GitHub Actions) و شما فقط دانلود می‌کنید.
  ب) برنامه را به‌صورت یک وب‌سایت (GitHub Pages) هم منتشر می‌کند که با لینک باز می‌شود و روی گوشی «نصب» می‌شود.

پیش‌نیاز: بهتر است این کارها را با کامپیوتر انجام بدهید. آپلود پوشه‌ها با گوشی در GitHub دشوار است.

۱) ساخت حساب و مخزن
  1. به github.com بروید و Sign up کنید (ایمیل و رمز).
  2. بالا سمت راست روی + بزنید و New repository را انتخاب کنید.
  3. یک نام انگلیسی بدهید، مثلاً azmoonyar. گزینه‌ی Public را بگذارید (برای Pages رایگان لازم است). Create repository را بزنید.

۲) آپلود فایل‌ها
  1. فایل ZIP را روی کامپیوتر Extract کنید.
  2. در صفحه‌ی مخزن روی «uploading an existing file» (یا Add file > Upload files) بزنید.
  3. همه‌ی محتوای پوشه‌ی استخراج‌شده را بکشید و رها کنید: پوشه‌های www و docs و .github و فایل‌های package.json و capacitor.config.json و .gitignore.
     (پوشه‌ی .github مخفی است. اگر کشیده نشد، مرحله‌ی «اگر .github آپلود نشد» را ببینید.)
  4. پایین صفحه روی Commit changes بزنید. آپلود فایل بزرگ index.html چند دقیقه طول می‌کشد.

   اگر .github آپلود نشد:
     - Add file > Create new file بزنید.
     - در کادر نام دقیقاً بنویسید:   .github/workflows/build-apk.yml
     - محتوای فایل build-apk.yml.txt را کپی و داخل کادر بچسبانید و Commit کنید.

۳) ساخت APK (الف)
  1. در مخزن، تب Actions را باز کنید. اگر پیام فعال‌سازی آمد، گزینه‌ی «I understand my workflows» را بزنید.
  2. روی Build APK در ستون چپ و بعد Run workflow بزنید.
  3. حدود ۵ تا ۱۰ دقیقه صبر کنید تا تیک سبز بخورد.
  4. روی اجرای تمام‌شده بزنید. پایین صفحه در بخش Artifacts فایل azmoonyar-apk را دانلود کنید (یک ZIP است؛ داخلش app-debug.apk است).
  5. app-debug.apk را روی گوشی اندروید ببرید و نصب کنید (باید «نصب از منابع ناشناس» را برای مرورگر یا مدیر فایل مجاز کنید).
  این APK از نوع debug است: برای استفاده‌ی شخصی خوب است، ولی برای انتشار در بازار (کافه‌بازار/گوگل‌پلی) باید نسخه‌ی release با امضا ساخته شود.

۴) منتشر کردن به‌صورت وب‌سایت (ب)
  1. در مخزن به Settings > Pages بروید.
  2. در بخش Build and deployment، Source را روی «Deploy from a branch» بگذارید.
  3. Branch را main و پوشه را /docs انتخاب کنید و Save بزنید.
  4. بعد از چند دقیقه لینک شما می‌شود:  https://نام-کاربری.github.io/نام-مخزن/
  5. این لینک را در مرورگر گوشی باز کنید و از منو «Add to Home screen» (افزودن به صفحه‌ی اصلی) بزنید تا مثل یک اپ نصب شود.

۵) وقتی سوال‌های جدید اضافه شد
  فایل index.html جدید را در دو جا جایگزین کنید: www/index.html و docs/index.html (Add file > Upload files و همان نام). بعد Actions را دوباره Run workflow کنید.

نکته‌ها
  - ساخت سوال با هوش مصنوعی و ذخیره‌ی فایل از «بانک سوال» فقط داخل Claude کار می‌کند؛ در APK و وب‌سایت غیرفعال است. آزمون‌ها، سوال‌ها، تصویرها و آمار کار می‌کنند.
  - آمار و سوال‌های واردشده روی هر دستگاه جدا ذخیره می‌شود.
  - اگر Actions خطا داد، متن خطا را برای من بفرستید تا اصلاح کنم.
