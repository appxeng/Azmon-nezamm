آزمون‌یار نظام مهندسی — پروژه‌ی آماده‌ی APK و وب‌سایت

- www/ : نسخه‌ی مخصوص ساخت APK (Capacitor)
- docs/ : نسخه‌ی مخصوص انتشار روی GitHub Pages و نصب PWA
- .github/workflows/build-apk.yml : دستور ساخت خودکار APK در GitHub
- GitHub-راهنما.txt : راهنمای قدم‌به‌قدم (از اینجا شروع کنید)
- build-apk.yml.txt : کپی متنی همان فایل، برای وقتی که پوشه‌ی .github آپلود نشد

راه‌های دیگر ساخت APK: سرویس‌های آنلاین تبدیل HTML به APK، یا Android Studio با دستورهای npm install و npx cap add android و npx cap sync.
سوال‌ها هنوز با ویرایش فعلی کتاب‌ها تطبیق داده نشده‌اند و برچسب «تطبیق‌نشده» دارند.
